# CraftTree (제작트리)

ArcheRage 애드온. 만들 물건 이름을 치면 재료 트리를 펼치고 경매장 최저가를 붙여서
**만드는 게 싼지 사는 게 싼지**, 그리고 **경매장에서 살 것 · 만드는 순서**를 보여줍니다.

## 설치
[Releases](https://github.com/Corey-ahn/CraftTree/releases) 에서 `crafttree-버전.zip` 을 받아 풀고,
`crafttree` · `globals` 폴더를 `문서\ArcheRage\Addon\` 에 넣은 뒤 게임에 접속하세요.

## 쓰는 법
- 화면의 제작트리 아이콘 또는 채팅 `!ct` 로 창을 엽니다
  - [통합 일정표](https://github.com/Corey-ahn/Rage-DayPlan) 를 쓰고 있으면 아이콘 대신 일정표의 **[제작]** 버튼으로 엽니다
- 검색칸에 물건 이름 → 찾기 (두 글자부터 자동완성). 채팅 `!ct 물건이름` 으로 바로 찾아도 됩니다
- 줄 좌클릭 = 펼치기/접기 · 칩 클릭 = 사기/만들기 바꾸기
- **가방 포함**: 가방에 있는 재료만큼 덜 삽니다. 가방에 있는 재료는 바로 장보기에 넣고, 경매장 조회는 모자란 것부터 합니다
- **만들 개수**: 칸에 숫자를 넣거나 채팅 `!ct x10`
